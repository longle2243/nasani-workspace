MANUAL UPDATE

Các file cần cập nhật thủ công

  1. Tải hai file JSON bên dưới và thay file tương ứng trong portfolio/data/.
  2. Tải từng ảnh mới và đặt vào đúng đường dẫn repository hiển thị cạnh ảnh.
  3. Kiểm tra trang public sau khi thay file, rồi tự commit/push để GitHub Pages cập nhật.

Chưa có nội dung nào được publish bởi thao tác này. Không tải ảnh inline/base64 trong JSON.

Bản nháp cục bộ được tách khỏi dữ liệu public. Hãy sao lưu file xuất trước khi xóa dữ liệu trình duyệt.
